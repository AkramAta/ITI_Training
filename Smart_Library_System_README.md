# Smart Library Management System

## Description

A Python OOP-based library management system that allows
students, teachers, and librarians to manage books.

## Features

- Add books
- Remove books
- Search books
- Display all books
- Display available books
- Display borrowed books
- Borrow books
- Return books
- Student borrowing limit: 3
- Teacher borrowing limit: 5
- Exception handling

## OOP Concepts

- Inheritance
- Encapsulation
- Polymorphism
- Abstraction

## How to Run

1. Install Python.
2. Clone the repository.
3. Open the project folder.
4. Run:

python main.py
